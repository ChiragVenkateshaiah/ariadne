# Generated NetworkPolicies

Everything in this directory is generated by
`brain/scripts/generate_network_policies.py` from the World Model's `CALLS`
edges — **do not hand-edit these files**; regenerate instead:

```
cd brain
source .venv/bin/activate
python scripts/generate_network_policies.py <db_path> travel
kubectl apply -f ../deploy/security/generated/
```

The committed snapshot here reflects the topology as of the last regeneration
and is committed so `kubectl apply -f deploy/security/generated/` works
without first running the ingestion pipeline. It will drift if the SUT's
`SERVICE_CALLS` catalog (`brain/ariadne/graph/catalog.py`) changes without a
regeneration — the Adjudicator-gated reconciliation loop planned in
docs/ARCHITECTURE.md's Phase 2 is the eventual fix for that drift risk.
